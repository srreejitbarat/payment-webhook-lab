WHAT TO NOTICE

Duplicates are expected.
Duplicate effects are optional.

Receipt ≠ downstream event

A new event ID repeating the same terminal result adds a receipt, while the outbox keeps one business event. A failed signature adds neither.

Delivery can happen again

In the Java implementation, publishing and marking an event delivered are separate effects. A crash can cause redelivery; consumers still need an event ID deduplication check.
